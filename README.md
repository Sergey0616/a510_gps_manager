# 70mai A510 GPS Manager

Личное Android-приложение для загрузки GPS CSV с FTP регистратора 70mai A510, группировки точек в треки, просмотра маршрутов и экспорта GPX/CSV.

## Возможности

- FTP по умолчанию: `192.168.0.1:21`, пользователь `root`, пустой пароль.
- Путь FTP по умолчанию: `/mnt/other/4g_gps`.
- CSV: 13 полей, время Unix UTC, широта, долгота, скорость в поле 5 (км/ч).
- Новый трек при разрыве времени больше 60 секунд.
- GPX 1.1, сводный CSV, карта OpenStreetMap.
- Локальное хранение в каталоге приложения `A510_Exports/gps` и `A510_Exports/parsed`.

## Сборка на Linux / компьютере

Нужны Flutter stable, Dart из Flutter, Android SDK и JDK 17.

```bash
chmod +x build.sh
./build.sh
```

Скрипт создаст недостающую Android-обвязку Flutter, выполнит `flutter pub get`, `flutter analyze` и соберёт release APK. Результат: `build/app/outputs/flutter-apk/app-release.apk`.

## Сборка через GitHub Actions без ПК

1. Создайте GitHub-репозиторий и загрузите файлы этого проекта.
2. Откройте вкладку **Actions**.
3. Выберите **Build Android APK** и нажмите **Run workflow**.
4. После успешной сборки откройте запуск workflow и скачайте артефакт `a510-gps-manager-apk`.

## Важные ограничения

- APK пока не проверен на физическом 70mai A510. У FTP-сервера регистратора путь `/mnt/other/4g_gps` может отличаться от пути, видимого через FTP.
- FTP не шифрует данные. Используйте соединение только с собственной сетью регистратора.
- Получение SSID зависит от версии Android, разрешений и настроек геолокации. Автосинхронизация выполняется, пока процесс приложения работает.
- Использование OpenStreetMap требует доступного интернета для загрузки тайлов; сами GPS-треки хранятся локально.

## Дополнительные блоки: видео и диагностика

- Экран «Видео и фото» сканирует FTP-каталоги Normal/Front, Normal/Rear, Parking, Event и Photo.
- MP4/JPEG/PNG можно выбрать для загрузки; видео записываются напрямую в конечный файл в `A510_Exports/video/<категория>` без промежуточного `.part`-файла.
- Во время загрузки показываются объём, процент, скорость и приблизительное оставшееся время. Загрузку можно отменить; при ошибке незавершённый файл удаляется.
- Встроенный плеер использует `media_kit`; кнопка внешнего плеера передаёт файл Android-приложению, которое обрабатывает MP4 (например, VLC, если он установлен/выбран).
- В настройках можно запросить сведения из файлов конфигурации/системы, посмотреть последние строки журнала, перезапустить `main_app` или перезагрузить регистратор. Команды обслуживания требуют отдельного подтверждения.
- Информация о MAC/SSID/IP отображается как `N/A`, так как FTP/Telnet не гарантируют её получение этим способом.

### Важные ограничения

1. FTP/Telnet реализованы без шифрования и предназначены только для локальной доверенной Wi-Fi-сети регистратора.
2. FTP-каталоги и формат `LIST` могут отличаться между прошивками. Если сервер возвращает нестандартный формат списка, парсер списка файлов нужно адаптировать.
3. Доступ к `/proc`, `/etc` и командам Telnet зависит от того, какие права и файловую область предоставляет конкретная прошивка.
4. GitHub-адрес репозитория не задан и намеренно не выдумывается: добавьте реальную ссылку в `lib/screens/settings_screen.dart` после публикации проекта.
5. В этой среде отсутствуют Flutter/Dart SDK, поэтому после изменений `flutter pub get`, `flutter analyze` и сборку APK необходимо выполнить в окружении с Flutter SDK. Не считать исходники скомпилированными до успешного CI/build.
